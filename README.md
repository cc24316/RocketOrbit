# RocketOrbit
Aplicativo de produtividade gamificado que, a partir do início de uma sessão de foco, monitora o tempo de uso do dispositivo para calcular o progresso de uma missão espacial até um planeta de destino. Ao detectar a abertura de aplicativos distrativos, o sistema interrompe o avanço e gerencia metas diárias, limites de tela e recompensas por consistência.
